## Mục tiêu

Thực hành tổ chức bố cục, định vị phần tử, thiết kế giao diện
thích ứng và tạo hiệu ứng CSS. Vận dụng Bootstrap để xây dựng
giao diện phục vụ website thương mại điện tử.

## Nội dung thực hành

- Bài 7.1–7.4: Luồng hiển thị, định vị tương đối,
  định vị tuyệt đối và thứ tự chồng lớp.
- Bài 7.5–7.9: Float, clear và chồng lớp nội dung trên ảnh.
- Bài 7.10–7.11: Bố cục hai cột và ba cột.
- Bài 7.12–7.13: Media queries, viewport và menu thích ứng.
- Bài 7.14–7.18: Biến đổi, chuyển tiếp, bộ lọc ảnh và hoạt ảnh.
- Bài 7.19: Hệ lưới và các thành phần giao diện Bootstrap.

Bài 7.13 được thực hiện tiếp trên file lab07-exercise12.html
và hai file CSS desktop, mobile của bài 7.12.

## Hướng dẫn truy cập

1. Truy cập đường dẫn GitHub Pages ở trên.
2. Nhấn “Xem danh sách 19 bài”.
3. Chọn bài thực hành cần xem.
4. Với các bài responsive, thay đổi chiều rộng trình duyệt.
5. Với các bài hover, đưa chuột vào ảnh hoặc nút để xem hiệu ứng.

Có thể chạy trên máy bằng cách mở thư mục CSS-NangCao
trong VS Code và dùng Live Preview để mở index.html.
