## Nội dung thực hành

- **Lab08 — Language Foundations:** 11 Exercise về Console,
  chuỗi, ngày tháng, mảng, hàm và đối tượng.
- **Lab09 — DOM and Events:** 8 Exercise về chọn và thay đổi
  phần tử, xử lý sự kiện, gỡ lỗi và kiểm tra biểu mẫu.
- **Lab10 — jQuery:** 10 Exercise về bộ chọn, sự kiện,
  thao tác DOM, hiệu ứng, GET Requests và jqXHR.

## Chạy trên máy

Mở thư mục JavaScript-Labs bằng VS Code và chạy qua
máy chủ xem trước như Live Preview hoặc Live Server.
Truy cập index.html qua địa chỉ HTTP do công cụ cung cấp.

Các bài GET cần chạy qua máy chủ HTTP, không mở bằng file://.
